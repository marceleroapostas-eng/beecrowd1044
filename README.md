# Beecrowd 1044 - Múltiplos



## Descrição



Este programa resolve o problema 1044 do Beecrowd.



## Tecnologias utilizadas



- Java

- NetBeans

- Maven



## Entrada



A entrada contém dois valores inteiros A e B.



## Saída



O programa apresenta "Sao Multiplos" caso os valores sejam múltiplos entre si, ou "Nao sao Multiplos" caso contrário.
